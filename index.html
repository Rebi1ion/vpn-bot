📖 Инструкция по настройке VPN

Шаг 1. Скачай приложение Hiddify

📱 App Store (iOS) 🤖 Google Play (Android) 💻 GitHub (Win/Mac/Linux)

Или любой другой клиент, поддерживающий протокол VLESS.

Шаг 2. Добавь конфиг

  • Скопируй конфиг по кнопке выше
  • Открой приложение Hiddify
  • Нажми кнопку «+» (плюс)
  • Выбери «Добавить из буфера обмена»

Шаг 3. Настрой приложение (для Hiddify)

  • Рядом с кнопкой «+» нажми на ⚙️ Настройки
  • Выбери режим: VPN
  • В дополнительных настройках укажи регион: Другой

Шаг 4. Готово!

  • Нажми крупную кнопку подключения в центре
  • Разреши создание VPN профиля (при первом запуске)
  • Пользуйся интернетом без ограничений! 🚀
